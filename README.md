# Matematika NHF – celý semester

Jednostránkový výklad semestra matematiky na Národohospodárskej fakulte EUBA v poradí cvičení: vektory, matice, determinanty, inverzná matica, maticové rovnice, sústavy lineárnych rovníc, Leontiefov model, definičný obor, ekonomické funkcie, derivácie, dotyčnica, elasticita, extrémy a optimalizácia. Každá kapitola má časti čo to je, prečo to funguje, postup a riešený príklad.

Web: https://matuslenicky.github.io/matematika-nhf/

Študijná pomôcka, nie oficiálny materiál univerzity. Stránka sa neindexuje vo vyhľadávačoch (`noindex`).

## Zostavenie

- `src/vyklad.html` – výklad so vzorcami vopred vykreslenými MathJaxom (SVG), preto stránka nepotrebuje žiadny skript.
- `python build.py` – zloží `index.html` (landing page: úvod, prehľad kapitol, výklad, tlačidlo späť hore, svetlý aj tmavý režim).

Písmo IBM Plex (Google Fonts, SIL Open Font License); bez internetu sa použije systémové písmo.
